Glosario / Glossary

Español English Definición / Definition
Teoría del Color Color Theory Ideas que explican cómo funciona la combinación de los colores. / Ideas that explain how color combinations work.
Pantone Pantone Nombra colores para que diseñadores y marcas usen exactamente el mismo tono. / Name colors so that designers and brands use the exact same shade.
Experiencia de usuario User Experience Cómo se siente una persona al usar un producto, página o aplicación. / How a person feels when using a product, page, or application.
Accesibilidad Accessibility Crear productos, espacios o contenidos que puedan ser usados por todas las personas. / Create products, spaces, or content that can be used by everyone.
Diseño adaptivo Responsive design Forma de diseñar que ajusta la apariencia de una página según el tamaño de la pantalla. / A design method that adjusts the appearance of a page according to the screen size.
Moda Fashion Forma de expresión a través de la ropa, colores y estilos. / A form of expression through clothing, colors, and styles.
Diseño de moda Fashion design Proceso de crear prendas y accesorios. / Process of creating garments and accessories.
Colorimetría Colorimetry Estudio del color y su forma de cómo se usa. / Study of color and how it is used.
Armonía cromática Chromatic harmony La combinación de colores que se ven bien juntos. / The combination of colors that look good together.
Círculo cromático Color wheel Rueda que demuestra la organización de los colores y sus relaciones. / Wheel that demonstrates the organization of colors and their relationships.
Psicología del color Color psychology Estudio de cómo los colores puede influir en las emociones. / Study of how colors can influence emotions.
Tono Tone Tipo de color. / Color type.
Saturación Saturation Intensidad del color. / Color intensity.
Luminosidad Brightness Qué tan claro o oscuro puede ser un color. / How light or dark can a color be.
Complementarios Complementary Colores que son opuestos en el círculo cromático pero que generan un contraste. / Colors that are opposite each other on the color wheel but create a contrast.
Análogos Analogues Colores que están uno al lado del otro y crean una armonía suave. / Colors that are next to each other and create a soft harmony.
Triada Triad Combinación de tres colores equidistantes en el círculo cromático. / Combination of three equidistant colors on the color wheel.
Paleta de color Color palette Conjunto de colores seleccionados para un diseño. / Set of colors selected for a design.
Estética Aesthetics Aspecto visual que hace que algo se vea atractivo. / Visual aspect that makes something look attractive.
Concepto creativo Creative concept Ideas principal que inspira un diseño. / Main idea that inspires a design.
